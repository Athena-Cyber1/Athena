mini-services/llm-bridge/ (Bun :3015)
Le flux complet UI → moteur → pont → fournisseurs ne peut pas tourner sur un hébergement purement statique : la démonstration ci-dessus appelle l'endpoint public directement depuis le navigateur, ce qui suffit à montrer le HUD et la réponse du modèle, mais pas le pipeline complet. Pour celui-ci, suivre la rubrique « Stack local ».

◐ Lancer le stack en local

Prérequis : Bun ≥ 1.1 et Python ≥ 3.12.

# 1. Application Next.js (racine du dépôt)
bun install && bun run dev          → http://localhost:3000

# 2. Pont LLM (terminal séparé)
cd mini-services/llm-bridge && bun install && bun --hot index.ts

# 3. Moteur Athéna (terminal séparé)
cd mini-services/llm-chat && pip install fastapi uvicorn && bash daemon.sh
Le HUD détecte automatiquement les serveurs locaux (Ollama :11434, LM Studio :1234, llama.cpp :8080). Un modèle local sélectionné est appelé en OpenAI-compatible ; en cas d'échec, repli silencieux sur la cascade avec un toast discret « repli sur modèle auto ».
